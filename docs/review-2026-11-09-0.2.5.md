# Extension review: 0.2.5

Date: 9 November 2026. 0.2.5 makes the grading panel compact; correction,
extraction and privacy behaviour are unchanged. Counts and the archive checksum
are in [`review-2026-11-09-0.2.5.json`](review-2026-11-09-0.2.5.json).
Validation used synthetic Chromium fixtures with fictional data in all eight
languages; no Moodle site or published release was changed.

## What changed

| Area | Before | Now |
| --- | --- | --- |
| Steps | Three always-open cards; the panel scrolled on a laptop screen. | Three collapsible cards (`details`), each with a summary when closed. An open criteria or result card takes the free height, so the panel fits a 720 px high window without scrolling. |
| Which step is open | All of them. | Criteria when a student loads; also evidence when a file is skipped or no evidence is found; result while and after correcting. The teacher can open or close any card. |
| Evidence | Reference, submission and additional files as three always-visible lists. | Two collapsible groups: teaching material (reference and supporting files, with the add button) and the student submission. A group with a skipped file opens on its own; only one group opens at a time. |
| Header | Title row, context, a chip row with the grading mode and the AI chip, and the status line. | Title row, and the context with the AI chip on the same line. The grading mode is on the result card; the status line is in the footer above **Correct with AI**. |
| Criteria | A visible label and hint above each field. | The label stays for assistive technology; the hint is the tab tooltip. |

The browser check that expected a large grading mode under the header now
checks that a skipped file opens the evidence card and its group, that the
grading mode sits on the result card and that the add button is in the
teaching-material group. The criteria helper opens the criteria card before
selecting a scope.

## Not changed

The content script grows from 424 KB to 433 KB. The Office layout engines and
the attachment transfer remain as described in
[`review-2026-11-07-0.2.2.md`](review-2026-11-07-0.2.2.md).
