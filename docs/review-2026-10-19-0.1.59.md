# Corrector 0.1.59 local provider support

LM Studio is an explicit provider with default endpoint http://127.0.0.1:1234/v1, model discovery, optional session authentication, compatible JSON correction generation, and image content parts. Other local compatible servers can be configured with their actual API endpoint, using the same transport. llama.cpp, LocalAI, and vLLM are documented candidates; no individual live compatibility qualification was performed.

Settings now share provider definitions with the worker, provide discovered model suggestions, clear the old endpoint/model on provider selection, and reject stale initial-settings/model-list UI updates after user edits. HTTP is still allowed only for loopback hosts. Existing remote API settings still require HTTPS and an API key.

Validation: npm run check passed 35 tests. Isolated Chromium passed 48 checks, including model discovery, empty lists, generation, image requests, optional authentication, persistence, provider/key isolation, and existing grading regressions. The LM Studio default port did not respond during a read-only health probe, so generation was validated against a fictional compatible server. No application was installed, started, or reconfigured, and no live Moodle tab was changed.
