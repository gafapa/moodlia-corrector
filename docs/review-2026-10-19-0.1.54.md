# Simplified Side Panel — 0.1.54

The normal side-panel view now contains file names and purposes, saved teacher
instructions, and readable proposed grades and feedback. Provider/model
selectors, pasted/generated JSON, captured-data summaries, and diagnostics
remain available through three SVG icon buttons in the header. These views
reuse the original controls rather than replacing their state.

Buttons expose accessible names, native title tooltips, expanded state, and
the controlled view's ID. Opening a tool focuses its heading. Escape or the
back button returns to the main view and restores focus to the corresponding
icon. Only one tool view is shown at a time. Navigation resets the result and
returns to the main view while preserving saved instructions and AI settings.
The primary correction action remains in the footer. Success messages show
the review/save instruction; technical counters remain in diagnostics.

Validation: `npm run check` passed 24 unit tests, syntax checks, and the reader
build. `npm run test:browser` passed 28 isolated Chromium checks. Added cases
verify technical controls hidden by default, labelled icon navigation,
expanded state, Escape/focus restoration, settings visibility, and readable
feedback/grade output while JSON remains hidden. Existing reset, file-role,
saved-instruction, cancellation, and closed-tab regressions still pass.

Desktop, compact-width, and settings-view screenshots were inspected in two
bounded passes using fictional Moodle fixtures. The static UI detector returned
no findings, which does not constitute a complete accessibility audit. The
popup retains its existing layout; this change targets the in-page side panel.

`npm run package` builds the local 0.1.54 candidate. The accompanying JSON records
its source-content comparison and hash. The user's browser and live Moodle
fields were not changed. Reload the updated extension and Moodle page, after
saving any pending work, to activate the new panel.
