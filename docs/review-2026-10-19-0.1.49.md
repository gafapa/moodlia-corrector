# Navigation Reset — 0.1.49

The content script now watches navigation events, URL changes, student and
attempt identity, and submitted evidence. A DOM observer and periodic check
cover Moodle updates that change hidden input properties without navigation
events. Page exit cancels ongoing work, and persisted-page restoration starts
a new assistant session.

A reset clears the local assignment snapshot, generated and pasted correction
JSON, extra instructions and files, detected details, and per-page diagnostics.
It restores the correction controls and cancels the previous request by ID.
AI configuration remains available. Moodle grade and feedback fields are not
cleared or saved by a reset. An open panel re-extracts after a short debounce
to allow the new grader DOM to arrive.

Each navigation increments a local revision included in the grading snapshot.
Extraction and correction callbacks from an earlier revision cannot repopulate
the new panel or restore stale button states. Returning to the previous URL
does not restore its previous correction. A previous request's completion
cannot clear the active ID of a newer request.

Validation: `npm run check` passed with 20 unit tests, JavaScript syntax checks,
and the attachment-reader build. `npm run test:browser` passed 20 checks in an
isolated Chromium profile using fictional Moodle submissions and a loopback
provider. Added regressions cover clearing all per-page fields and uploads,
same-document URL changes, navigation during panel generation, a successful
fresh correction after cancellation, identity changes without a changed URL,
preserved Moodle form fields, and a full reload with a clean assistant.
Earlier actual Ollama checks were not repeated for this state-management change.

`npm run package` builds the local 0.1.49 ZIP; the accompanying JSON records
its source-content verification and SHA-256. The user's live Moodle tab was
not navigated, no real grades were changed, and the installed extension has
not been reloaded. Reload the updated extension and Moodle page when ready
to activate the new content script, after saving any pending Moodle edits.
