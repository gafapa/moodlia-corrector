# Extension review: 0.2.3

Date: 7 November 2026. 0.2.3 redesigns the grading panel; correction,
extraction and privacy behaviour are unchanged. Counts and the archive checksum
are in [`review-2026-11-07-0.2.3.json`](review-2026-11-07-0.2.3.json).
Validation used synthetic Chromium fixtures with fictional data in all eight
languages; no Moodle site or published release was changed.

## What changed

| Area | Before | Now |
| --- | --- | --- |
| Header | Title, three tool icons, grading mode and status. | Product name, the assignment and course, the student and attempt, the grading mode, an AI chip (model in use, green when ready) that opens the AI settings, and the status line. |
| Tools | Icons for AI configuration, correction JSON and data/diagnostics. | AI settings from the chip; correction JSON and data/diagnostics in a **More options** menu. Escape closes the menu or the view and returns focus to the control that opened it. |
| Main view | File list, three criteria fields one below the other, result. | Three numbered cards: evidence for the AI, teacher criteria in course / assignment / this-student tabs (arrow keys move between tabs; a dot marks a scope with text), result. |
| During a correction | A status line. | A progress card: read the files, review the evidence, write the grade and feedback, fill in the Moodle form, with a progress bar. |
| Result | Plain paragraphs. | A large proposed grade, the final comment, and one tile per criterion with its name in bold. |
| Panel markup | Written in one layout, then taken apart and rebuilt by position (`organizePanelWorkflow`). | Written once in its final structure. |

Every element the correction logic and the tests rely on keeps its `data-*`
hook. The browser checks were adapted to open the **More options** menu and to
select a criteria tab before typing in it.

## Not changed

The content script is about 20 KB larger (403 KB to 424 KB) for the new markup
and styles. The Office layout engines, the repeated prompt context per evidence
block and the base64 transfer of attachments remain as described in
[`review-2026-11-07-0.2.2.md`](review-2026-11-07-0.2.2.md).
