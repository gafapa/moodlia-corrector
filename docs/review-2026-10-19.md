# Corrector Review — 2026-10-19

## Reproduced Defects

The original Chromium regression applied a correction after the grader URL
changed from one fictional student to another. The original implementation
returned success and wrote the feedback and grade. Version 0.1.46 compares a
local snapshot before requesting AI, after generation, and before changing the
form. The snapshot covers the assignment, student, attempt, visible identity,
online submission, and submitted file URLs. It does not enter the AI prompt.

Rubric normalization previously replaced invalid or missing level indexes with
the first available level. These values now remain invalid and trigger the
existing repair/rejection path. Missing criterion feedback and duplicated
criterion identities cannot make an AI correction complete. Manual score
validation precedes all form edits.

The PDF reader previously rendered only pages without text. A fixture with
both text and a vector drawing demonstrated omitted visual evidence; it now
retains extracted text and renders the page for a vision model. Graphics count
toward the existing 12-image limit. Text-only PDF pages keep the text-only path.

Assignment and online submission extraction silently stopped at 12,000
characters. Both now preserve the full input, with a separate 60,000-character
limit checked before provider requests. Attachment limits are enforced while
reading the response body rather than after buffering the entire download.

## Validation

Final results: 20 unit tests and 15 Chromium checks passed, including the two
actual local Ollama checks. Dependency auditing reported zero vulnerabilities.
The ZIP contains 220 files, all byte-compared with the extension source; see
[machine-readable evidence](review-2026-10-19.json) for its SHA-256.

- `npm run check`: unit regressions, syntax checks, and bundled reader assets.
- `npm run test:browser`: isolated Chromium with a loopback provider and fictional Moodle pages.
- `node tests/browser-check.mjs --live`: the same browser checks plus actual local Ollama generation and a fictional arithmetic correction using `gemma3:4b`.
- `npm audit --audit-level=high`: dependency audit.
- `npm run package`: installable extension ZIP with bundled readers.

The browser cases cover valid form edits, unchanged forms after invalid scores,
stale correction application, navigation while generation is pending, mixed PDF
evidence, long statement/submission text, origin-rule isolation, cancellation,
and reference-file supervision. A live Moodle account and real student work
are not used. No actual Moodle grades are saved. Ollama settings and machine
CORS configuration are unchanged. A synthetic local check verifies transport
and structured output, not educational grading quality.

This review prepares a local 0.1.46 candidate. Publication and installation
into the user's normal browser are separate from these isolated-profile checks.
