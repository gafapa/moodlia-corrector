# Direct Grading and Panel Layout — 0.1.47

The open Moodle grader was inspected without changing its fields. Its grade
control is a text input named `grade`, labelled `Calificación sobre 10`, with
no `max` attribute. Maximum extraction now uses associated labels or ARIA
labels when there is no explicit maximum. Disabled, read-only, hidden, and
unrelated controls are excluded. Rubric and guide detection retain priority.
The method is displayed immediately in both the panel and popup.

The grader's navigation, document preview, grade region, and action bar are
positioned against the viewport. Shrinking the body alone did not resize their
positioning area. While the AI panel is open, the body now establishes that
area for absolute and fixed descendants and reserves the panel's responsive
width. Horizontal overflow remains scrollable. Closing removes these scoped
styles and restores the original inline sizing and transition.

## Verification

- `npm run check`: bundled reader build, JavaScript syntax checks, 20 unit tests passed.
- `node tests/browser-check.mjs --live`: 18 Chromium checks passed in an isolated profile, including two actual local Ollama checks with fictional evidence.
- Browser regressions cover label-only maxima, Spanish/Galician/English labels, decimal maxima, unknown maxima, disabled inputs, guide priority, both mode indicators, TinyMCE feedback, and positioned Moodle regions at 1280, 960, and 600 pixels.
- Closing restores the fixed action bar to the full viewport width. A visual inspection of the fictional 1280-pixel fixture confirms the panel and Moodle regions occupy separate areas.
- `npm audit --audit-level=high`: zero vulnerabilities.
- `npm run package`: local ZIP; archive contents are byte-compared with the extension source in the accompanying JSON evidence.
- Impeccable's static UI detector returned no findings using its reduced regex fallback; this does not constitute a complete accessibility audit.

These are synthetic layout and form fixtures derived from structural DOM
inspection. Real student data was not sent to AI and no live Moodle grade was
changed or saved. Ollama and operating-system configuration were not changed.
The local 0.1.47 candidate has not been published or reloaded into the user's
normal browser; installed copies require an extension reload and a refreshed
Moodle page to use the updated content script.
