# Saved Correction Instructions — 0.1.50

The side-panel instruction field and popup now use a shared binding to
`chrome.storage.local`. Text saves on input, remains available after page or
browser restarts, and synchronizes across open extension views. Clearing the
field saves an empty string. No browser sync or remote storage is used.

The navigation reset preserves these instructions while still clearing old
corrections and uploaded files. Local writes are serialized to preserve typing
order. Initial loading does not overwrite text entered in the meantime, and
storage errors are reported without discarding the visible text. Correction
payload construction waits for the initial preference read.

Validation: `npm run check` (20 unit tests, syntax checks including the new
shared script, and bundled reader build); `npm run test:browser` (22 isolated
Chromium checks). Fictional regressions verify saved text shared by the popup
and panel, popup reload, student navigation, full document reload, and durable
clearing. The existing reset and stale-correction checks continue to pass.

`npm run package` prepares the local 0.1.50 candidate; archive byte comparison
and SHA-256 are recorded in the accompanying JSON. The user's live page was
not reloaded and no real grades were changed. The updated extension and Moodle
page must be reloaded to activate the new scripts, after saving pending edits.
