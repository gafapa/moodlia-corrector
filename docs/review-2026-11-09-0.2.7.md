# Extension review: 0.2.7

Date: 9 November 2026. 0.2.7 lets the teacher choose which evidence files are
sent and opens ZIP archives. Counts and the archive checksum are in
[`review-2026-11-09-0.2.7.json`](review-2026-11-09-0.2.7.json).

## What changed

| Area | Before | Now |
| --- | --- | --- |
| Choosing evidence | Every supported file was sent. | Each file has a check box; supported files start checked. Unchecked files are not sent, and the request tells the model the teacher left them out (`teacher-excluded`), so their absence is not penalised. The choice resets for each student. |
| ZIP archives | Skipped as an unsupported format. | Listed in the panel with a check box per file. Checked supported files are extracted in the offscreen reader and sent one by one with the archive's role. Limits: 500 files per archive, 20 MB per file, 48 MB of selected content. |
| Moodle downloads | Files were downloaded only when correcting. | A Moodle ZIP is downloaded once when the panel shows it, to list its contents. The privacy policy says so. |
| Launcher | Stayed visible beside the open panel. | Hidden while the panel is open; it returns, with keyboard focus, when the panel closes. |

Archive and file names stay out of the request, like other original filenames.
New browser checks cover a real ZIP fixture (listing, disabled unsupported
entries, sending only checked files), an unchecked reference file reported as
`teacher-excluded`, focus on the check boxes and the launcher. The reader
checks refuse oversized archives and extract only the requested files.
