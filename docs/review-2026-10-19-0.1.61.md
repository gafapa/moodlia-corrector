# Corrector 0.1.61 inline settings and site activation

The grading panel now contains Simple provider/model selection and Advanced full configuration. Advanced reuses the options document inside an extension-origin frame with tab-bound, short-lived authorization. The shared form supports server address/port/path, model discovery/filtering/manual IDs, session key save/delete, generation tests, and cancellation. Mode controls stay visible while scrolling. A new status revision rejects stale availability results; navigation clears the advanced frame and cancels connection tests.

Activation follows the MoodlIA Rubrics interaction: click the icon to activate the current grader, choose Always activate on this site to persist automatic activation for that Moodle installation, and disable it to unregister future injection. The installation base path is preserved. Repeated activation creates one assistant. Native tabs permission was removed, scripting was added, and static content injection was replaced with remembered-site dynamic registration. Existing AI/attachment network permissions remain independent of this activation policy.
