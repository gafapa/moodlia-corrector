# Embedded Grader Layout Fix — 0.1.48

Live DOM inspection reproduced a collapsed review region (0 pixels high), a
grade region reduced to its padding (31 pixels), and an action bar above the
viewport. The theme applies `position: inherit` to `#page`. Forcing the body
to `position: relative` made that mostly empty wrapper a new positioning
area, only one pixel tall.

The fix removes the forced positioning. The existing body transform still
provides the reduced positioning area for viewport descendants, while the
theme's inherited positioning retains its original behavior.

A temporary CSS override was applied through browser developer tools to the
already-open Moodle page, without reloading it or modifying grade fields.
The review and grade regions both returned to 744 pixels high, with the
60-pixel action bar at the bottom of the 889-pixel viewport. This transient
override lasts until navigation; the extension source contains the durable
fix. The installed extension still needs reloading for future page loads.

The fictional Chromium fixture now includes the same inherited-position
wrapper. It asserts usable review and grade heights, action-bar bottom
placement, and no overlap with the AI panel at 1280, 960, and 600 pixels.
It also verifies full-width restoration after closing the panel. No real
student evidence was sent to AI, no Moodle grades were saved, and no machine
configuration was changed.

Validation: `npm run check` (20 unit tests, syntax and reader build),
`npm run test:browser` (16 isolated Chromium checks), and `npm run package`.
Archive verification details are in the accompanying JSON evidence. Earlier
0.1.47 live Ollama results were not rerun for this CSS-only fix.
