# File Purpose Preview — 0.1.52

The panel and popup show a shared file preview before correction. Each row
contains the local filename and purpose, grouped into assignment references,
student submissions, and teacher-provided additional material. Original student
filenames are displayed locally; AI prompt anonymization remains unchanged.
The preview identifies online text separately and explains that planned files
are validated when correction starts rather than claiming they are already read.

The panel list is visible in its workflow; the popup disclosure opens by
default. Manual uploads update the list immediately. Navigation clears old
uploads and re-renders the newly extracted page. Filenames use text nodes,
with wrapping for long names, rather than HTML insertion.

Validation: `npm run check` passed 22 unit tests, syntax checks, and the reader
build. `npm run test:browser` passed 25 Chromium checks. Fictional fixtures
verify filenames and purposes in both views, initial popup visibility, added
teacher-file attribution, and removal after navigation. A screenshot inspection
confirmed the panel preview at desktop width. The static UI detector used its
reduced regex fallback and returned no findings, which is not a full audit.

`npm run package` prepares the local 0.1.52 ZIP. The accompanying JSON records
its source-content comparison and hash. No real Moodle grades or live browser
state were changed. Reload the updated extension and Moodle page after saving
any pending edits to activate the new script.
