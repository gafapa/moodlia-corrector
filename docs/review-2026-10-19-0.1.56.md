# Default Criteria and Compact Panel — 0.1.56

Course and assignment criteria now maintain installation-local last-used
defaults. Context loading restores an existing value first, including an empty
string saved by clearing the field. Only a context without a saved value
receives a copy of its default, which is then saved under that context's key.
Concrete-case criteria retain their student/attempt keys and never acquire a
default. Existing legacy instructions remain available through explicit
recovery; the previous global value is not silently spread across Moodle sites.

File previews now show compact grouped filenames and one purpose explanation
per group. Every file retains its full name, role, tooltip, and accessible
label. Long lists scroll inside a keyboard-focusable region limited to 240px.
The grading mode and detection status sit below the header tool buttons with
stronger typography and contrast.

Validation: `npm run check` passed 25 unit tests, syntax checks, and reader build.
`npm run test:browser` passed 36 isolated Chromium checks. New or extended cases
verify persistent copying across full document loads, preservation of saved
and intentionally blank criteria, empty cases in new contexts, no default
copying to another site, compact file height and file-purpose accessibility,
and status position/font prominence below the icons. Fictional desktop and
compact screenshots were inspected. The UI detector's reduced regex fallback
reported no findings; this is not a complete accessibility audit.

`npm run package` builds the local 0.1.56 candidate. The accompanying JSON
records byte comparison with the extension source and its SHA-256. No real
Moodle data was sent to AI and the user's installed browser extension was not
reloaded. Reload the updated extension and Moodle after saving pending edits.
