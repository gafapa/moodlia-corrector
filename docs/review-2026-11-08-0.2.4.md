# Extension review: 0.2.4

Date: 8 November 2026. 0.2.4 fixes how OpenDocument files are recognised;
the panel, correction and privacy behaviour are unchanged. Counts and the
archive checksum are in [`review-2026-11-08-0.2.4.json`](review-2026-11-08-0.2.4.json).

## What changed

| Area | Before | Now |
| --- | --- | --- |
| OpenDocument recognition | Only the `mimetype` entries `opendocument.text`, `.spreadsheet` and `.presentation` (or no entry) were accepted. A file saved from LibreOffice Writer/Web (`text-web`), a master document or a template was shown as "Skipped · unsupported format content". | `text`, `text-web`, `text-master`, `text-master-template` and `text-template` are read as ODT; `spreadsheet-template` and `presentation-template` as ODS and ODP. Their `content.xml` body is the same. |
| Tests | ODT fixtures had no `mimetype` entry, so the exact match was never exercised. | A browser check reads ODT archives with `text`, `text-web`, `text-template` and `text-master` mimetype entries. |

A teacher-supplied Writer/Web ODT that 0.2.3 skipped was read with the 0.2.4
reader: 11 pages, their text and 11 page images, with no limitations reported.
The file itself is not part of the repository.

## Not changed

Content script size, the Office layout engines and the attachment transfer
remain as described in [`review-2026-11-07-0.2.3.md`](review-2026-11-07-0.2.3.md).
