# Extension review: 0.1.76

Date: 27 October 2026. This review covers the current local working tree,
including the earlier PDF/Ollama fixes and the 0.1.75 Office reader follow-up.
Existing unpublished changes were retained. No production Moodle page, student
submission, active browser installation or published release was modified.

## Findings and fixes

| Priority | Finding | Result in 0.1.76 |
| --- | --- | --- |
| P1 | JSON responses outside streaming had no equivalent memory/output bounds. | Response bodies stop at 8 MB while reading, even without `Content-Length`; generated content stops at 200,000 characters. Readers are cancelled and released on failure. |
| P1 | A small embedded GIF/BMP could request a very large decoded bitmap before document limits were checked. | Headers are checked before native decoding: at most 16,777,216 pixels and 16,384 pixels per edge. Oversized images are counted as `embedded-image-size-limit` in the receipt; document text remains available. Office image counts are checked before further conversion. |
| P2 | A compatible non-streaming response cut off with `finish_reason: length` could still supply valid JSON and be accepted. | Non-stop completion reasons are rejected before correction parsing. |
| P2 | Attachment byte budgets trusted missing, negative or understated `sizeBytes`. | Sizes must be non-negative safe integers. The larger of declared size and measured content size is charged against the existing 4 MB/file and 10 MB/operation budgets. |
| P2 | Condensing long notes silently removed the tail after 60,000 characters. | The complete bounded note is sent to the condensing request; provider context errors remain explicit instead of hiding lost observations. |
| P2 | Applying a correction could modify feedback before discovering locked rubric controls, or force disabled radios into a selected state. | Known feedback/editor/rubric targets are checked before the first write. Disabled, read-only, inert and explicitly ARIA-disabled targets are rejected, with an error translated into all eight interface languages. |
| P2 | The complete online-text box included images inside `[hidden]` or `[aria-hidden="true"]` descendants. | Explicitly hidden images are excluded consistently with text extraction; the CSS-hidden complete Moodle submission remains readable. |
| P2 | Overlapping provider changes could combine a captured provider with another provider's profile or restore a delayed old selection. | Selection revisions discard stale lookups/responses and invalidate pending status reads. Profile lookup uses the captured provider. |

Four new core regression groups first failed against the previous implementation
and passed after the fixes. A separate deterministic race test covers rapid
provider changes. Chromium checks additionally cover locked feedback and rubric
fields, hidden image descendants, oversized image headers and the earlier Office
cancellation/ODT text regressions.

The locale browser harness also had an initialization race: a visible language
selector was asserted before its asynchronous preference load. It now waits for
the expected value before checking the localized interface.

## Review coverage

- **Permissions and activation:** manual activation, remembered HTTPS Moodle
  installations, registration migration, tab action handling and removal.
  Broad HTTPS host access is still declared for arbitrary Moodle installations,
  selected hosted providers and signed file-storage redirects. This permission
  was not silently expanded or narrowed during the review.
- **Provider transport:** destination validation, redirect rejection, HTTP host
  permission checks, extension-scoped Origin handling, session-key binding,
  model discovery, generation, JSON/NDJSON/SSE, deadlines, cancellation and
  disconnect handling.
- **Evidence:** current-attempt Moodle online text and images; assignment
  references versus student submissions; source-code text; downloads, HTTPS
  redirects and cookie boundaries; PDF text/page images; DOCX/ODT; decompression,
  byte/text/image limits; original-document receipts and block-note synthesis.
- **Grading integrity:** Case > Assignment > Course > assignment requirements;
  preserved rubric identities and allowed levels; score limits; stale-student
  rejection; feedback/editor writes; disabled controls; no automatic saving of
  Moodle's grading form.
- **Storage and privacy:** provider profiles, destination-bound session keys,
  remembered sites, teacher criteria/defaults, navigation isolation and legacy
  recovery. Structured names, Moodle URLs and unmentioned filenames remain
  excluded from inference payloads. Evidence itself can contain identifying
  information; this is not guaranteed anonymization.
- **Interface:** popup, grading panel, simple/advanced options, authorized frame,
  keyboard focus, semantic labels/status messages, model search, resize/overflow
  behavior and all eight locales. Existing visual identity and workflows remain.
- **Distribution:** manifest/runtime version agreement, generated content and
  locale bundles, bundled parser assets, archive contents and current store
  metadata validation.

## Validation

- `npm run check`: 80 automated tests passed.
- `npm run test:browser`: 75 Chromium integration checks passed with fictional
  Moodle and provider fixtures.
- `npm run test:locales`: ten checks passed, including all eight locales.
- `npm audit --audit-level=moderate`: zero known dependency vulnerabilities.
- UI mechanical detector: no findings for `src/content/moodleContent.js`.

Live inference: `node tests/live-pdf-check.mjs` with a 900,000 ms harness deadline
passed against installed local `gemma4:e4b`. The fictional nine-page PDF with two
rubric criteria completed four requests in 123,039 ms, returned the expected
10/10 and both rubric selections, retained its student-submission PDF receipt
and did not describe the supplied PDF as missing. Final usage was 4,319 prompt
tokens and 973 generated tokens. The isolated harness injects
`options.num_ctx = 131072` only into its own replayed requests; the extension
still leaves the server's context setting unchanged.
