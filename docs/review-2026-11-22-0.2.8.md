# Extension review: 0.2.8

Date: 22 November 2026. 0.2.8 fixes the findings of a security and correctness
review of 0.2.7. Counts and the archive checksum are in
[`review-2026-11-22-0.2.8.json`](review-2026-11-22-0.2.8.json).

## Security

| Finding | Before | Now |
| --- | --- | --- |
| Student text read as the assignment | The statement and its attachments were searched in the whole grader page, including the student's online text. A `class="intro"` block with a link could make the service worker download any same-origin Moodle page, such as a gradebook report, with the teacher's session and send it to the AI. | Online text, submission comments and attempt history are excluded from statement and attachment discovery. |
| Another student's file | Any `pluginfile.php` link of the submission file area counted as the student's file, including links written in the online text. | Only file links rendered by Moodle outside student-written content count. |
| Downloads with the teacher's session | Any HTTPS URL on the Moodle origin. | Only Moodle file areas that fit the role: `assignsubmission_file` or `assignsubmission_onlinetext` for student evidence, any `pluginfile.php` file area for assignment material. Other URLs are skipped without a request. |
| Panel open to page scripts | Open shadow roots; synthetic clicks could start a correction or turn on automatic correction. | Closed shadow roots in store installations (open only in unpacked builds, for automated checks). Correct, Apply and automatic correction require trusted input; automatic correction reads the extension's own state, not the check box. |
| Settings page | Controls were wired before the embedding check. | Controls are wired only after authorization. |
| Provider errors | Shown verbatim in the panel. | Credentials are masked and the text is limited to 300 characters. |

## ZIP archives

Empty, encrypted, oversized and nested entries are shown as omitted with their
reason and cannot be checked. The reader reads the central directory, never
extracts encrypted entries, and skips extracted entries whose CRC-32 does not
match. One bad entry no longer discards the archive or stops the correction.
Large archives start with only the files that fit the 40 MB total checked.
Empty archives and archives with a root `content.xml` open as ZIP archives.
Unreadable entries are reported to the AI as an unsupported format. The Correct
button stays disabled while an archive opens, and a failed listing is retried
when a correction is requested.

## Privacy texts

The privacy policy, the eight store descriptions and the dashboard data-use text
now state that automatic correction of the next student sends each uncorrected
student's work when the teacher moves to that student.

## Deferred

- `https://*/*` remains a required host permission. Making it optional changes
  how sites are activated, how Moodle files stored behind external storage
  redirects are downloaded, and how AI endpoints are reached. It needs
  verification on real sites.
- `use_dynamic_url` for the settings page was tried and reverted: the authorized
  settings frame no longer loaded in Chromium checks. A website can therefore
  still detect that the extension is installed; it cannot use the page.
